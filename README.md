# 🛍️ ShopAI

## AI-Powered Shopping & Bundle Agent

ShopAI is an AI-powered shopping assistant built using Python and Streamlit.

It helps users discover products, search and filter items, compare products, save favourites, manage a shopping cart, receive smart recommendations, and create product bundles based on their budget.

---

## ✨ Features

- 🔍 Product Search
- 🗂️ Category Filtering
- 💰 Price Filtering
- ↕️ Product Sorting
- ❤️ Wishlist Management
- 🛒 Shopping Cart
- 🧾 Demo Checkout
- ⚖️ Product Comparison
- ⭐ Product Reviews and Ratings
- 🤖 AI-Powered Smart Recommendations
- 🔄 Smart Alternative Finder
- 📦 Dynamic 2-Product Bundles
- 🎁 Dynamic 3-Product Bundles
- 🧩 Bundle Compatibility Checker
- 📜 ShopAI Request History
- 📊 Merchant AI Insights
- 🎨 Interactive Dashboard
